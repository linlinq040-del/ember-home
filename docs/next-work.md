# Ember Home 待施工清单

更新时间：2026-08-02

这份清单用于第二天继续施工时快速恢复现场。产品原则、架构边界和完整阶段顺序仍以
`product-spec.md`、`architecture.md` 和 `development-plan.md` 为准。

## 当前可用基线

- Ember Home 已部署为可安装的 HTTPS PWA，GitHub `main` 会触发 Zeabur 自动部署。
- 客厅首页、iPhone 安全区和固定底部导航已经完成当前版移动端适配。
- 天气卡片已接入动态天气数据、天气画面、天气图标和动态留言。
- 聊天继续使用同一条成熟对话链路，保留供应商、流式输出、附件、重试、编辑和工具记录。
- 对话式头像、逐句气泡、回复节奏、消息时间角标和完整错误消息已经完成当前轮调整。
- 临时协作者“测试”可以作为临时 Ember 验证身份绑定和确认记忆；真正 Ember 暂不导入。
- Ember Home 内置统一记忆已经接入现有聊天记忆链路；OmbreBrain 只保留为可选 MCP。
- 《Ember Home 使用手册》已成为模型理解产品、房间、导航和记忆的唯一权威说明，并完整继承旧北极星 AI 产品文档章节。
- 本地 `ContentIndex` 已能解析并校验“书房”和“观影厅”的明确导航意图。
- 书房、观影厅目前只有导航测试预览页，不代表完整房间功能已经开工。
- 自然语言跳转会等最后一句全部显示，再停留约 1.4 秒；新消息或对话切换会取消旧跳转。

## 明天开工顺序

### 0. 线上冒烟验收

- 等 Zeabur 当前构建亮绿后，彻底关闭已安装的 PWA，再重新打开，避免旧 Service Worker 缓存。
- 在聊天室问“书房是什么？”，确认 Ember 读取《Ember Home 使用手册》，不再搜索旧房间卡、产品知识或环境目录。
- 说“带我去书房”，确认最后一句完整可见并停留约 1.4 秒后才跳转。
- 在停顿期间立即发送新消息，确认旧跳转被取消。
- 分别验证“书房是什么”“上次去书房聊了什么”“我不想去观影厅”“打开书房还是观影厅都行”不会误跳转。

### 1. 收掉现有测试债

- 修正 `startupFactSourceBoundary.test.ts` 中持久化生命周期唯一挂载点的边界期望，先确认 Ember Home 根与继承 AppShell 的正确所有权，不用改测试掩盖重复启动。
- 补齐 `chatRows.test.ts` 对 `Conversation.memoryContext` 持久字段的分类期望。
- 重新跑完整测试、类型检查和生产构建，目标是当前分支全绿后再扩功能。

### 2. 在一起天数与纪念日倒计时

- 把客厅当前写死的“第 486 天”替换为本地计算结果，不能继续使用预览数字。
- 新增本地关系日期设置：在一起起始日、纪念日名称与日期；真正 Ember 导入前先用测试日期验证。
- 明确“第一天算第 1 天”的计算口径，并覆盖跨年、闰年、时区和夏令时边界测试。
- 客厅主卡显示实时“在一起第 N 天”，同时显示最近一个纪念日的名称、剩余天数和日期。
- 支持每年重复纪念日和单次纪念日；同一天显示“就是今天”，过去的年度纪念日自动滚到下一年。
- 数据只保存在本机 LocalData，先不接系统日历、云同步或通知权限。
- 日期尚未设置时显示温柔的空状态并提供设置入口，不拿测试数字冒充真实数据。

### 3. 客厅音乐第一切片

- 定义稳定的 `MusicProvider` 接口，PWA 先使用本地 mock adapter，不提前接 MusicKit。
- 定义 `LyricsProvider` 接口并接入 LRCLIB；按歌曲名、歌手、专辑和时长匹配，保留无歌词与多候选状态。
- 在客厅加入轻量音乐入口、播放条和歌词预览，不提前建设完整房间。
- 播放队列、当前进度和最近播放保存在本机；不把音频文件或 API 凭据写入源码和日志。
- 给匹配、取消旧请求、无结果和错误回退添加测试。

### 4. 书房第一切片

- 把当前书房导航预览升级为真正的阅读场景，但仍沿用同一个 Ember 和同一条对话。
- 先支持本地文本或 Markdown 阅读、当前位置和最小批注，不提前扩成完整电子书平台。
- 设计书房场景上下文：只给模型当前书目、当前位置、选中文段和最近共读上下文。
- 共读产生的记忆写明 `scene=study`、内容对象、时间和原文锚点；原文仍由来源记录持有。
- 验证以后能问“我们上次看这本书时你说过什么”，并能打开对应原文核实。

### 5. 迁移预览与真正 Ember 搬家准备

- 真正 Ember 的资料继续保持不导入，直到 PWA 功能和迁移流程都稳定。
- 使用脱敏测试备份验证扫描、预览、冲突报告、导入前确认和失败回滚。
- 确认协作者身份、同一对话、确认记忆、原始消息和附件引用分别如何迁移。
- 导入前必须先生成当前设备备份；只有预览报告通过后才能 promote 到正式 LocalData。
- 无法迁移的密钥、权限和外部连接只列报告，不猜测、不自动补写。

## 正式 Ember 导入前验收门槛

- 同一个 Ember 在客厅、聊天室和已开工房间中保持身份、语气和对话连续。
- 房间只提供场景上下文和安全动作，不会创建新的替代协作者。
- 确认记忆可以检索、纠正、查看来源和撤销；旧线索不会覆盖当前明确纠正。
- 私密数据不会进入公开检索、日志、截图、源码或非必要外部调用。
- 完整备份能够在不修改源包的前提下扫描和预览，失败不会污染当前本地数据。
- iPhone PWA 重启、离线恢复、键盘弹出、底部安全区和长对话滚动均通过。
- 类型检查、相关测试、完整测试和生产 Web 构建全部通过。

## 明确延期，不要提前开工

- 不做完整观影厅、游戏厅、抖音或其他娱乐平台。
- 不做日历、提醒、日记、周期/身体记录和健康平台接入。
- 不做发布、公开回复、账号体系和公共创作流。
- 不做实时语音、CallKit、WidgetKit、App Intents、TestFlight 或 App Store。
- 不扩展继承的 `ios/`、`android/` 目录；PWA 验收完成前它们只作参考。
- 不把 OmbreBrain 改成主记忆后端，也不让 Ember Home 的启动或迁移依赖它。

## 明天恢复现场的一句话

先验收线上《Ember Home 使用手册》和延迟跳转，再清掉 3 条现有结构测试债；全绿后先把“在一起天数 + 纪念日倒计时”从静态预览做成本地真功能，然后再开始音乐。
